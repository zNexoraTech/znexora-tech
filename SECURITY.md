# Security Policy

ZNexora Tech takes the security of this website and its automation seriously.

## Reporting a vulnerability

If you find a security problem in this website or repository, please **do not open a public issue or pull request**.

Report it privately instead:

- Use **Report a vulnerability** on the **Security** tab of this repository, or
- Email **aicreativestudio.777@gmail.com** with the subject "Security report".

Please include what you found, where (page or file), and steps to reproduce it. We aim to reply within 5 business days and will credit you once it is fixed, if you wish.

## Scope

- The website: https://znexoratech.github.io/znexora-tech/
- The code and automation in this repository

Please do not run automated scans that put heavy load on the site, try to access other people's data, or use social engineering.

## Our protections

- Strict Content Security Policy, no third-party scripts, tracking or cookies
- Raw HTML blocked in articles; all content reviewed before publishing
- Secrets stored only as encrypted GitHub Actions secrets
- Secret scanning, push protection and Dependabot alerts enabled
- Two-factor authentication on all maintainer accounts
